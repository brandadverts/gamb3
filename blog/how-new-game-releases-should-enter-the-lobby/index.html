How new game releases should enter your lobby

Dozens of new games ship every week. The difference is not having them all in the lobby but knowing why each one is there.

The Gamb Gaming teamNovember 16, 20262 min read

Switch on a new aggregator and your catalogue can jump by thousands of titles overnight. Every week brings more: crash games, live game shows, few-second instant games, slots themed for a single market. Finding games is not the problem. Deciding which ones earn a place in the lobby is.

What has changed lately

Across industry reports and trade shows, a few trends stand out:

  • Short rounds, quick decisions. Crash, mines and dice games are now their own category,

played on mobile in short sessions.

  • Live game shows. Next to classic live tables, presenter-led formats with wheels and

bonus rounds.

  • Verifiable outcomes. Games whose round results can be checked afterwards are becoming

an expectation, especially in instant games.

  • Local content. Theme, language and art direction chosen for one market.

None of these performs the same way everywhere. A "most played new releases" list is a shortlist for your lobby, not proof.

Five checks before a game goes live

  1. Market approval. Is the game certified for this market? Some markets do not allow

certain game types or features, such as bonus buy, at all.

  1. Return-to-player configuration. If the provider offers several RTP settings, which one

is active should be on record.

  1. Wallet behaviour. Can bonus balance be used on this game, and what share counts towards

wagering? Write the rule before the game opens.

  1. Risk. Instant games run a very high number of rounds. Abuse rules and limits have to

match that pace.

  1. Measurement. Decide up front how you will judge the game: turnover only, or returning

players and session length too?

The lobby is a decision, not a shop window

Putting a new game in the top row is easy. The hard part is looking at the data two weeks later and being able to take it down. That needs a lobby ordered by rules rather than by hand, able to look different per market and segment, with every change logged.

A setup that works looks like this: a new game enters a trial slot, is shown for a set period to a set segment, gets measured, and then either moves into the main lobby or stays in the catalogue.

Provider count or integration quality?

Forty providers looks impressive. But each one is a separate reconciliation, a separate failure scenario and a separate certificate to track. One API, shared reconciliation and shared reporting matter more than the number on the slide.
